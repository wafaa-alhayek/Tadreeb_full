# نظام إدارة التدريب الميداني — Tadreeb

مشروع تخرج + برنامج CodeMap مع Taqat. نظام بيجمع الطالب والجامعة والمشرف الأكاديمي وجهة التدريب بمكان واحد: من التقديم على التدريب لحد إصدار الشهادة.

## هيكل المستودع

```
tadreeb_full/
├── frontend/      ← واجهات React (حسين + عبد الله)
├── backend/       ← خادم Django (وفاء) — لسا فاضي
├── docs/          ← الاتفاقات والأدلة
└── .github/       ← قالب الـ Pull Request
```

## ابدأ من هون

1. اقرأ [docs/TEAM_AGREEMENT.md](docs/TEAM_AGREEMENT.md) — القواعد اللي اتفقنا عليها.
2. اقرأ [docs/WHO_DOES_WHAT.md](docs/WHO_DOES_WHAT.md) — مين مسؤول عن أي ملف.
3. اقرأ [docs/GIT_GUIDE.md](docs/GIT_GUIDE.md) — طريقة الشغل على GitHub خطوة بخطوة.
4. شغّل الواجهة: [frontend/README.md](frontend/README.md).

## الفريق

| الدور | الاسم |
|---|---|
| Front-End — بوابة الطالب | حسين |
| Front-End — بوابة الإدارة والمشرفين وجهة التدريب | عبد الله أبو الليل |
| Back-End — Django وقاعدة البيانات والـ APIs | وفاء |
