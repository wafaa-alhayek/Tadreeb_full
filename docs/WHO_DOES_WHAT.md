# مين بيشتغل على شو

كل ملف مكتوب بأوله اسم المسؤول عنه. هاي الخريطة كاملة.

## المكونات المشتركة — `frontend/src/components/`

| الملف | شو بيعمل | المسؤول | بيستخدمه |
|---|---|---|---|
| `Button.jsx` | زر موحّد (أساسي / ثانوي / حذف) | حسين | الكل |
| `Input.jsx` | حقل إدخال مع عنوان ورسالة خطأ | حسين | الكل |
| `Card.jsx` | صندوق أبيض لتجميع المحتوى | حسين | الكل |
| `StatusBadge.jsx` | شارة حالة الطلب بالعربي واللون | حسين | الكل |
| `Sidebar.jsx` | الشريط الجانبي | حسين | البوابتين |
| `Header.jsx` | الشريط العلوي | حسين | البوابتين |
| `DataTable.jsx` | جدول مع بحث | عبد الله | الإدارة بشكل أساسي |
| `StatCard.jsx` | بطاقة رقم إحصائي | عبد الله | لوحات التحكم |

## الصفحات حسب الوحدة (Module)

| الوحدة | بوابة الطالب — حسين | بوابة الإدارة — عبد الله | الخادم — وفاء |
|---|---|---|---|
| 1 المستخدمون | ✅ `StudentLoginPage` ✅ `StudentHomePage` | ✅ `AdminLoginPage` ✅ `AdminDashboardPage` ✅ `StudentsListPage` | تسجيل الدخول، الأدوار، ملف الطالب، الأهلية |
| 2 فرص التدريب | استعراض الفرص + التقديم | إدارة الجهات والفرص | Organizations, Opportunities, Applications |
| 3 التوزيع والموافقات | متابعة حالة الطلب | المراجعة والتوزيع | محرك حالات الطلب |
| 4 متابعة التدريب | ملف التدريب، السجل اليومي، الحضور | اعتماد السجلات | Training Record, Daily Log, Attendance |
| 5 التقييم | رفع التقارير، التقييم | الزيارات والتقييمات | Reports, Visits, Evaluations |
| 6 الشهادة والإدارة | عرض الشهادة وتحميلها | لوحة الإحصائيات والتقارير | Certificate, QR, Audit Log |

✅ = في نسخة أولية بالقالب (ببيانات وهمية) — المطلوب تكملتها وربطها بالـ API الحقيقي.

## ملفات مشتركة (أي تعديل عليها بنتفق عليه أولًا)

- `src/api/client.js` — عبد الله (بالتنسيق مع وفاء)
- `src/constants/statuses.js` — وفاء بتحدد الرموز، الفرونت بيحدد الأسماء والألوان
- `src/styles/index.css` — حسب ملف Brand Guidelines (هبة)
- `src/App.jsx` — كل واحد بيضيف روابطه بقسمه بس
